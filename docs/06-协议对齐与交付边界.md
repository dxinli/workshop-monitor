> 本文档处理系统与外部系统之间的协议约束，以及交付范围的界定。产品文档只说明"须遵循客户规范"，本文档说明"遵循什么、基线取值怎么定、差异怎么消化"。

---

## 1. 外部协议约束

### 1.1 来源

客户要求上行数据结构与其既定的接入规范保持一致。该规范由客户在合作确认后提供，规范条款本身不是本项目产物。

### 1.2 采用的姿态

**对齐结构与协议，不对齐业务模型。**

| 维度 | 是否对齐 | 说明 |
|---|---|---|
| 分层定位 | 对齐 | 按"业务应用 — 物联管理平台 — 边缘物联代理 — 末端设备"四层划分职责 |
| 设备标识 | 对齐 | 以终端序列号作为终端标识来源 |
| 数据分类 | 对齐 | 按模拟量、开关量分类，控制类仅预留字段 |
| 主题结构 | 对齐 | 主题层级模板与命名分隔方式 |
| 报文结构 | 对齐 | 报文头字段与时间、序号语义 |
| 业务模型 | 不对齐 | 不建模对方业务拓扑 |
| 业务术语 | 不对齐 | 界面与文案使用车间工业用语 |
| 主站流程 | 不对齐 | 不做真实主站联网与流程对接 |

判定口径：任何一条对齐要求若无法映射到车间测点或车间业务动作，本期不采纳，并在接口规范中写明排除原因。

## 2. 对齐内容

### 2.1 分层职责

| 层级 | 本项目对应物 | 职责 |
|---|---|---|
| 业务应用 | 业务界面 | 面向用户的业务闭环 |
| 物联管理平台 | 接入服务 + 存储 + 告警 | 设备接入、数据汇聚、告警 |
| 边缘物联代理 | 融合终端 + 采集应用 | 协议转换与本地自治 |
| 末端设备 | 传感器（仿真或真实） | 数据采集 |

### 2.2 标识

1. 终端以序列号作为标识来源，不另设业务编码；
2. 设备标识由 `终端序列号 + 总线编号 + 从站地址` 构成，保证全局唯一；
3. 测点标识在此基础上追加测点编码，避免跨终端重号；
4. 序列号长度与字符集以客户规范为准；规范到位前使用约定基线取值，由配置项约束。

### 2.3 数据分类

| 分类 | 含义 | 本期实现 | 对应测点 |
|---|---|---|---|
| 模拟量 | 连续测量值 | 是 | 温度、振动、电流、电压、功率、电能、温湿度、气压 |
| 开关量 | 二值状态 | 是 | 门磁、急停、光幕 |
| 控制量 | 开关控制 | 否，仅预留字段位 | — |
| 调节量 | 参数设定 | 否，仅预留字段位 | — |

### 2.4 主题结构

1. 上行主题按 `/edge/{终端序列号}/{业务类型}/up` 模板分层，业务类型至少区分数据、事件、状态三类；
2. 下行主题按对应模板预留，本期不实现业务逻辑；
3. 主题名称、层级顺序、大小写、分隔符以客户规范为准；规范到位前以上述模板为基线；
4. 接口规范须同时给出"对齐主题"与"内部标准主题"两套命名及映射关系，由配置开关选择；
5. 变更主题命名不得影响存储、告警与界面。

### 2.5 报文结构

1. 报文保留规范要求的头部字段（设备标识、报文类型、时间、序号等）；
2. 测点值按分类组织，模拟量携带数值、单位与质量，开关量携带状态；
3. 外部格式与平台内部模型之间由协议适配层单向转换，适配层是平台侧唯一允许自研的组件之一；
4. 完整字段定义与映射表见[接口规范](../02-设计/04-接口规范.md)。

### 2.6 业务用语

1. 协议层可保留规范字段名与分类名，界面层必须翻译为工业用语；
2. 界面、告警文案、通知卡片、导出报表中不得出现与车间场景无关的业务术语；
3. 终端在界面中的称谓统一为"融合终端"或"车间边缘终端"；
4. 车间、产线、设备、测点、能耗、安全为界面一等业务维度；
5. 演示讲解顺序固定为先讲业务场景，再补充协议结构依据。

## 3. 基线取值

客户规范在合作确认后才提供。为保证本期可落地、可演示、可核对，本项目按行业常见做法确定基线取值，并在签约时逐项确认。

### 3.1 基线清单

| 项 | 基线取值 | 性质 |
|---|---|---|
| 上行主题模板 | `/edge/{终端序列号}/{业务类型}/up` | 可演示事实，非占位符 |
| 业务类型 | 数据、事件、状态三类 | 同上 |
| 终端序列号形态 | 固定前缀 + 4 位数字 | 同上 |
| 报文头字段数 | 8 个规范字段（另含 1 个本地扩展字段） | 同上 |
| 数据分类 | 模拟量、开关量 | 同上 |
| 串口参数 | 9600 / 8 / N / 1 | 同上 |

上述取值全部落在配置与文档中，可在现场打开报文与配置文件逐项核对。

### 3.2 差异消化方式

| 待核对项 | 规范到位后的改动方式 | 是否触及代码 |
|---|---|---|
| 主题字符串与层级顺序 | 改主题模板配置 | 否 |
| 终端序列号长度与字符集 | 改终端配置 | 否 |
| 报文头字段名 | 改契约字段映射表 | 否 |
| 质量码取值域 | 改质量码映射表 | 否 |
| 数据分类字段别名 | 改映射表 | 否 |

原则：差异在配置层消化，不改存储、界面与业务代码。确认动作与影响分级见 §5 的 P-E01~P-E05。

## 4. 交付边界

### 4.1 本期交付

| 类别 | 内容 |
|---|---|
| 文档 | 立项、需求、设计、编码、测试、部署运维五阶段文档 |
| 源代码（自研） | 采集应用、接入服务 |
| 仿真件源代码 | 从站模拟器、数据构造器、通知接收端 |
| 配置资产 | 告警流程定义、界面面板定义、点表与阈值配置 |
| 容器镜像 | 全部服务的构建脚本与离线镜像包 |
| 部署文件 | 容器编排文件、环境变量样例、启停与重置脚本 |
| 演示材料 | 演示剧本、演示前检查表、备用录屏 |

### 4.2 明确不交付

| 项 | 说明 |
|---|---|
| 硬件 | 传感器、终端、网关等硬件采购与安装 |
| 现场施工 | 总线布线、阻抗与抗干扰治理 |
| 终端原厂能力 | 原厂应用商店上架、固件升级、终端网管 |
| 真实主站联网 | 与客户物联管理平台的实际联网、证书认证、注册接入 |
| 真实通知租户 | 企业通知通道的租户申请与生产推送 |
| 企业级权限 | 用户、组织、角色、细粒度权限体系 |
| 安全合规 | 等保测评、安全加固、高可用与容灾 |
| 移动端 | 应用与小程序 |
| 性能承诺 | 正式容量压测报告与调优 |
| 控制类功能 | 远程控制、参数下发、远程升级（接口规范仅预留字段） |
| 其他协议 | 本期协议之外的工业协议 |

### 4.3 边界声明

本期证明的是**软件链路正确性**：接口读取 → 边缘处理 → 上行 → 平台业务闭环。不证明现场通信质量、硬件兼容性与长期运行稳定性。
