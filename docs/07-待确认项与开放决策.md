## 4. 已关闭 / 已决策

以下事项在实现过程中已由任务单「偏差」段定案，登记在此是为了避免后来者重新发起同一讨论。

| 事项 | 结论 | 落点 |
|---|---|---|
| 两套主题命名是否同形 | **同形，仅前缀不同**：`grid` = `/edge/{esn}/…`，`internal` = `/workshop/{esn}/…` | 接口规范 §5.1；`config/topics.json` |
| 终端 MQTT 账号是否带 `edge-` 前缀 | **不带**。账号名即终端序列号，ACL / 口令文件 / `.env` 变量名三者一一推导 | 接口规范 §4.2 |
| `threshold` 表 15 条还是 95 行 | 配置文件里是 **15 条模板**，按「终端 × 测点」展开为 **95 行**投影 | 数据库设计说明书 §9 D-04 |
| 点表是否需要显式配置版本 | **需要**，顶层 `configVersion` 写入 `terminal.config_version`，V-12 据此判断是否记配置加载事件 | 接口规范 §3.7 |
| 配置校验写成脚本还是命令 | **Go 命令** `cmd/config-tool`，与 edge-agent 启动校验共用 `internal/config` | ADR-14 |
