# 015 健康检查与自检

> 计划任务：M14（复杂度 S）　状态：待办

## 要建什么

两个自研服务的 `/healthz`，以及 `scripts/preflight.sh` 的 12 项部署后自检。

## 验收

- [ ] `edge-agent` 的 `/healthz` 返回 config / serial / mqtt / cache 四项
- [ ] MQTT 断开但采集正常时返回 **200 降级**，不是 503
- [ ] 串口任一总线打不开返回 503
- [ ] 缓存达 80% 时报告降级
- [ ] `proto-adapter` 追加 evaluate 字段：`queueDepth` / `dropCount` / `activeAlarmCount` / `debounceKeys`
- [ ] 活动告警数与库中未恢复数不一致时报告异常
- [ ] `make preflight` 12 项全过；任一项失败输出原因并退出非 0

## 阻塞

- 005（采集侧状态）、008（接入侧状态）

## 加载

- rules：`.claude/rules/edge-agent.md`（健康检查）、`.claude/rules/adapter-evaluate.md`（健康）、`.claude/rules/deploy-config.md`
- 健康检查契约：`../../docs/02-设计/02-详细设计说明书.md` §5

## 偏差

无。MQTT 断开返回 503 会被编排重启容器，打断采集并丢内存中未刷盘数据——这是设计内降级，不是故障。
