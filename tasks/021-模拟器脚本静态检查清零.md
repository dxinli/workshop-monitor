# 021 模拟器与验收脚本静态检查清零

> 计划任务：缺陷修复（复杂度 S）　状态：已完成

## 要建什么

`sim/` 与 `scripts/` 全部 Python 代码通过 Python LSP（pyright 系，含 basedpyright）静态检查：
逐文件消掉诊断报错（未用变量与参数、Optional 解引用、非法方法覆写、运算符类型不匹配、
已移除 API 的死代码），并让 LSP 解释器指向 `.venv-sim`，第三方依赖可解析。

控制接口的信号归属按会话确认的方案落地：`run()` 统一接管 SIGINT/SIGTERM，
uvicorn 侧 `capture_signals()` 放行，删掉已随 uvicorn 0.30 移除的
`install_signal_handlers` 赋值（当前是死代码，注释「信号统一由本函数处理」与实现不符）。

## 验收

- [ ] `make sim-test` 通过（除信号接管外行为无变化）
- [ ] `grep -rn "install_signal_handlers" sim/` 为空
- [ ] Python LSP 对 `sim/`、`scripts/` 无 ✘ 级诊断（import 解析类由 `pyrightconfig.json` 指向 `.venv-sim` 解决）
- [ ] 模拟器进程收到 SIGTERM 后 5 秒内退出（最小复现脚本实测）
