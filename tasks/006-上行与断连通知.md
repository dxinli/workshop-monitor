# 006 上行与断连通知

> 计划任务：M6（复杂度 M）　状态：待办

## 要建什么

按上行契约发布三类消息（数据 / 事件 / 状态），注册 LWT，序号原子递增且跨重启续接。`internal/model/` 放与接口规范对应的结构体。

## 验收

- [ ] 三类消息可分别订阅到，主题随 `MQTT_TOPIC_SCHEME` 切换
- [ ] 报文头 8 个规范字段齐全：`schemaVersion` / `msgType` / `msgId` / `esn` / `seq` / `collectTime` / `sendTime` / `backfill`
- [ ] 序号单调递增；进程重启后从队列最大序号续接，**不归零**（`BR-02`）
- [ ] 同一次采集的多个测点共享同一 `seq`（`BR-04`）
- [ ] `sendTime` 由本任务写入，`collectTime` 沿用 005 产出，两者不得混用
- [ ] 终端异常退出时，订阅方在 3 个上报周期内收到 `OFFLINE`（LWT，`BR-27`）
- [ ] 采集失败的点仍在数组中且 `value=null`，不省略
- [ ] `internal/model` 只有结构体，无方法无校验

## 阻塞

- 005（采集产出）、003（Broker 可用）

## 偏差

无。`esn` 与主题中的终端标识必须完全一致，不一致时整条判 `IDENTITY_MISMATCH`。
