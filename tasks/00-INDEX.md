# 任务清单

对应 `../../docs/01-立项/01-项目开发计划.md` §4.3~§4.7 的 M1~M17，共 18 份任务单。M8 拆两片（落库与终端状态），其余一一对应。

## 怎么用

一次会话只取一份任务单，不要连读多份。

1. 按依赖顺序取「可开工」的一行
2. 读该任务单的 `## 加载` 段，只读它列出的规则来源与 rules
3. 按 `CLAUDE.md` 的 Testing 段在 seam 上做红-绿
4. 按 `CLAUDE.md` 的 Done Check 两轴各过一遍
5. 把该行的状态改成「已完成」，提交到 `feat/<模块>-<简述>` 分支并开 PR 合入 `develop`
