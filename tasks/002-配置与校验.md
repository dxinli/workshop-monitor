# 002 配置与校验

> 计划任务：M2（复杂度 S）　状态：待办

## 要建什么

5 台终端的点表配置、告警阈值、配置校验 schema，以及 `make verify-config` 与 `make seed` 两个命令。

配置文件是唯一权威源，数据库只是供界面读取的投影。

## 验收

- [ ] 5 份 JSON，终端标识 `ESN-ZX-0001`~`0005`，与安装位置一一对应（`BR-01`）
- [ ] 5 份合计 10 总线 / 50 从站 / 140 测点，V-10 数量断言通过
- [ ] 测点标识按 `terminalId + busId + slaveAddr + pointCode` 拼装，顺序固定不得调整（`BR-05`）
- [ ] 每个测点同时定义属性与告警规则，规则可为空（`BR-45`）
- [ ] V-01~V-11 每条独立校验，失败输出**具体字段与原始值**，不只说"配置错误"
- [ ] `make verify-config` 对合法配置返回 0，对写坏的配置返回非 0
- [ ] `make seed` 生成可导入 SQL，导入后 `point` 表 140 行
- [ ] 把某测点缩放系数改成 0，`make verify-config` 报 V-05 并指名该测点
- [ ] 终端、总线、设备、测点、采集周期、阈值、主题命名全部可配置，不硬编码（`BR-43`）
- [ ] 阈值配置覆盖 AL-01~AL-15 共 15 条规则
