# 005 采集轮询与换算

> 计划任务：M5（复杂度 L）　状态：待办

## 要建什么

采集应用核心：按点表周期轮询、寄存器值换算为工程值、标记质量、产出批次。装配 `cmd/edge-agent/main.go`。

本任务不含上行（006）与缓存（007），产出通过日志观察。

## 验收

- [ ] 14 点工程值与模拟器设定值一致，含 32 位累计量高低字拼装
- [ ] 采集周期稳定 5 秒；同批测点共享同一 `collectTime`，取批次**开始**时刻（`BR-07`）
- [ ] 通信超时 → `TIMEOUT`(2) 且值为空；异常码 → `DEVICE_EXCEPTION`(1)；CRC 错 → `CRC_ERROR`(3)
- [ ] 超量程 → `OUT_OF_RANGE`(5) 且**保留数值**，不置空（`BR-16`）
- [ ] 采集失败不沿用上一次值，不填 0（`BR-15`）
- [ ] 两条总线各一个协程，一条阻塞不影响另一条
- [ ] 配置非法时拒绝启动（非 0 退出）并输出具体字段，对应 V-01~V-11（`BR-44`）
- [ ] `codec.toEngineering` 有表驱动测试，期望值来自手算而非照抄实现

## 质量码

权威定义在 `../../docs/02-设计/04-接口规范.md` §8（冻结线 A）。固定 9 个值，不得增删改名，不得用字符串字面量散落代码：

| quality | 名称 | value 规则 | 方向 |
|---:|---|---|---|
| 0 | `GOOD` | number | 边缘产生 |
| 1 | `DEVICE_EXCEPTION` | null | 边缘产生 |
| 2 | `TIMEOUT` | null | 边缘产生 |
| 3 | `CRC_ERROR` | null | 边缘产生 |
| 4 | `PARSE_ERROR` | null | 边缘产生 |
| 5 | `OUT_OF_RANGE` | **保留数值** | 边缘产生 |
| 6 | `STALE` | number / null | 平台侧判定，**边缘不产生** |
| 7 | `SIMULATED` | number | 仿真件 |
| 8 | `MANUAL` | number | 仿真件 |

`quality ≤ 4` 时 `value` 必须为 `null`；`5~8` 保留数值。

**两个易错点**

- 补传不是质量码。它是报文头 `backfill` 布尔字段，与 `quality` 正交（`BR-17` 把它列进质量标识是业务口径，实现必须落到 `backfill`）。
- 超时是 `TIMEOUT`，不是 `COMM_TIMEOUT`。

## 三个时间（`BR-06` `BR-10`）

| 字段 | 产生方 | 只能用于 |
|---|---|---|
| `collectTime` | 本任务 | 业务时间轴：曲线、告警判定、排序、补传落位 |
| `sendTime` | 006 | 计算上报延迟、判断是否补传 |
| `receiveTime` | 008 | 计算链路延迟、排查卡顿 |

统一 int64 毫秒时间戳。三个时间不得互换，平台不得用接收时间补齐采集时间。
