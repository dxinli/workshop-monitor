# 007 本地缓存与补传

> 计划任务：M7（复杂度 L）　状态：待办

## 要建什么

上行失败时落盘、三上限裁剪、恢复后按序限速补传。用 bbolt 做本地持久化。

## 验收

- [ ] 断开 Broker 后采集不中断，数据进本地队列（`BR-19`）
- [ ] 三上限任一先到即生效：7 天 / 30 万条 / 512 MB（`BR-20`）
- [ ] 达上限按 FIFO 丢最旧，每累计 1000 条上报一次 `CACHE_DROPPED`，不得静默（`BR-21`）
- [ ] 任一维度达 80% 上报 `CACHE_WARNING`，同级别不重复上报（`BR-22`）
- [ ] 恢复后按序号正序补传，保留原 `collectTime`、更新 `sendTime`、`backfill=true`（`BR-23`）
- [ ] 补传限速：单批 ≤ 500 条、批间隔 ≥ 50 ms（`BR-24`）
- [ ] 补传期间采集协程不停（`BR-25`）
- [ ] 收到 PUBACK 才出队；超时未确认不出队（`BR-26`）
- [ ] `cache.trim` 有测试覆盖三上限触发与丢弃计数
